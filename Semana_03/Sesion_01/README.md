# Semana 3 · Sesión 1 (sesión 4 del curso) · Del chat a la API

**Tema:** qué recibe realmente un modelo de IA cuando le escribes, la diferencia entre *system prompt* y *user prompt*, y cómo llamar a un modelo desde Google Colab con tu propia clave. El taller es **guiado**: lo hacemos juntos, celda por celda.

## Qué lograrás
- Explicar qué es el system prompt, el user prompt y la respuesta del modelo.
- Crear tu clave de API y guardarla de forma segura en los Secretos de Colab.
- Llamar a un modelo por API y probar tu system prompt con las mismas 6 pruebas de la sesión 3.
- Explicar por qué un modelo no responde igual dos veces (temperatura).
