## Cómo usar este repositorio
1. Entra a la **semana** y **sesión** que quieres revisar.
2. `presentacion/`: presentación de la clase (`.pptx`, o `.html` interactivo que se abre en el navegador).
3. `actividades/`: guías de retos y ejercicios.
4. `notebooks/`: cuadernos de Python. Ábrelos en [Google Colab](https://colab.research.google.com/) (**Archivo → Subir cuaderno**) o con el enlace «Abrir en Colab» de cada sesión.
