# Actividad · ¿Machine learning o IA generativa?
**Trabajo en grupos, en salas de Zoom por colores**

## Cómo funciona
1. **Elige una sala de color.** Cada sala puede tener **máximo 4 personas**. Si una sala ya está llena, elige otra.
2. **Reparte roles** (pueden rotar):
   - **Moderador/a:** da la palabra y cuida el tiempo.
   - **Vocero/a:** presenta la respuesta del grupo cuando volvamos al grupo grande.
   - **Escriba:** anota las respuestas y las razones en la tabla.
   - **Verificador/a:** pregunta “¿por qué?” y revisa que todos opinen.
3. **Discutan las 8 situaciones.** Para cada una, acuerden una respuesta: **ML**, **GEN** (IA generativa) o **AMBAS**, y una razón en una frase.
4. **Volvemos al grupo grande.** Para cada situación habla **una persona por sala** (según lo que su grupo acordó) y los demás grupos dicen si coinciden o no, y por qué.

> No importa tener todas “bien”. Lo importante es poder **justificar** la respuesta.

## Pistas para decidir
- Si la IA **predice o clasifica** a partir de datos → suele ser machine learning.
- Si la IA **crea** contenido nuevo (texto, imagen, audio, código) a partir de una instrucción → es IA generativa.
- Muchas soluciones reales **combinan** las dos.
